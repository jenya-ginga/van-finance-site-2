# Подключение бэкенда — что уже работает и что нужно донастроить

Сайт остаётся статическим (HTML/CSS/JS), но теперь на Vercel добавлены
serverless-функции (папка `/api`) — это и есть "бэкенд": код, который
выполняется на сервере, а не в браузере посетителя, и может безопасно
хранить секретные ключи.

**Важно:** всё это заработает только после деплоя на **Vercel** (см.
инструкцию, которую я давал раньше). На GitHub Pages `/api`-функции не
запустятся — GitHub Pages отдаёт только статические файлы.

---

## 1. Форма обратной связи (contact.html) — 2 минуты, бесплатно

Сейчас форма отправляет данные на `https://formspree.io/f/YOUR_FORM_ID` —
это placeholder, реального адреса пока нет.

**Что сделать:**
1. Зайди на https://formspree.io и зарегистрируйся (бесплатный план —
   50 писем в месяц, этого более чем достаточно на старте)
2. Создай новую форму ("New Form"), укажи свою почту, куда должны
   приходить заявки
3. Formspree даст тебе ID вида `xyzabcde` — скопируй его
4. Открой `contact.html`, найди строку:
   ```html
   <form id="contact-form" data-endpoint="https://formspree.io/f/YOUR_FORM_ID">
   ```
   и замени `YOUR_FORM_ID` на свой ID
5. Закоммить и запушь — форма сразу заработает

Пока это не сделано, форма покажет посетителю честное сообщение
"форма ещё не подключена" вместо тихого проглатывания данных.

## 2. Курс Банка Англии (Bank Rate) — уже работает, ничего делать не нужно

На страницах калькуляторов и в статье про ставки теперь показывается
живой актуальный официальный Bank Rate Банка Англии (сейчас, например,
3.75%) — берётся из открытой базы Банка Англии, ключ не нужен.

Работает автоматически на Vercel благодаря файлу `api/base-rate.js`.
Обновляется само, кешируется на 6 часов, чтобы не дёргать источник лишний раз.

## 3. Проверка авто по гос. номеру (налог + MOT) — нужна бесплатная регистрация в DVLA

На странице `tools/vin-check.html` появился блок "Free tax & MOT status
check" — он пробивает реальный госномер через официальный DVLA API
(Vehicle Enquiry Service) и показывает марку, цвет, год, статус налога и
техосмотра (MOT).

**Что сделать (займёт 1-3 дня из-за одобрения DVLA):**

1. Подай заявку на API-ключ:
   https://register-for-dvla-electronic-services.dvla.gov.uk
   (или через портал разработчика:
   https://developer-portal.driver-vehicle-licensing.api.gov.uk)
   — выбери "Vehicle Enquiry Service (VES) API". Это бесплатно для
   информационных/сравнительных сайтов вроде твоего.
2. DVLA пришлёт API-ключ на почту после одобрения
3. Зайди в свой проект на vercel.com → Settings → Environment Variables
4. Добавь переменную:
   - **Name**: `DVLA_API_KEY`
   - **Value**: ключ, который прислал DVLA
5. Нажми "Save", потом сделай Redeploy проекта (Vercel → Deployments →
   три точки у последнего деплоя → Redeploy)
6. Готово — проверка по номеру заработает с реальными данными

Пока ключ не добавлен, форма честно покажет "ещё не настроено" вместо
ошибки или выдуманных данных.

## Что дальше можно подключить (не сделано пока)

- **MOT-история (полная, с прошлыми прохождениями)** — отдельный DVSA MOT
  History API, посложнее в настройке (OAuth2, client id/secret). Могу
  сделать отдельным шагом, если понадобится.
- **HPI-проверка (финансовые обременения, статус утиля, пробег)** — это
  всегда платные коммерческие API (HPI, Experian AutoCheck и т.д.),
  бесплатных полноценных аналогов не существует — здесь без партнёрской
  интеграции с провайдером не обойтись.
- **Реальные ставки конкретных лендеров** (Moneybarn, Zuto и т.д.) —
  публичного API с их актуальными ставками не существует, эти цифры
  всегда нужно обновлять вручную или через партнёрское API самого лендера
  (обычно доступно только официальным брокерам).
